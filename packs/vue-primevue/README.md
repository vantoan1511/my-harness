# Vue 3 + PrimeVue 4 Pack for my-harness

This pack provides UI development guidelines, component standards, and comprehensive reference recipes for Vue 3 + PrimeVue 4 applications.

## Contents
- **Skills**:
  - `ui` — Comprehensive patterns for DataTable, Forms, Animations, Layouts, and Theming.
- **Rules**:
  - `vue-primevue-standards.md` — Canonical component & directive guidelines.

## Installation into a Project

```bash
python /path/to/my-harness/harness.py add-pack vue-primevue
```
